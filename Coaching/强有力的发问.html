# 强有力的发问

强有力的发问是意味着教练要有能力通过提出问题，来揭示出必要的信息，为教练关系和客户带来最大的利益。ICF对其具体要求如下：

  1. 提出的问题反映出积极聆听和对客户视角的理解。
  2. 提出的问题唤起发现、领悟、承诺或行动。
  3. 提出开放的问题，带来清晰的思维、更多的可能性或新的学习。
  4. 提出的问题推动客户向他们渴望的目标前进，而不是要求客户为自己辩解或向后看。

这项能力是建立在积极聆听的基础上的，如果没有聆听的基础，那发问就不可能会真正的有力量。强有力的发问有一个目的就是推动教练对象从他们现在的位置去往他们想要去的地方。这个过程不只是重新安排或组织教练对象的现有想法，而且要促使他们更深入、更广阔、更灵活的思考。发问需要深入聆听到的价值观、前提假设、信念和视角进行深入探讨，一次教练会谈中发问越是有唤起性，就越能唤醒人的新思考和觉察。

# 教练的发问

教练应该鼓励探索教练对象的视角、前提假设、信念、价值观、需要、渴望、恐惧以及激情。教练要用有力地发问，让这些概念探讨表现出来。教练在发问的过程需要具备一个“新的眼睛”，它让教练能够以不同的方式看待各种事物。教练的发问也能帮助客户超越他们目前的思维去探索关于自身新的思维方式。这种唤起式发问必须要带来新的思考，新的思考也应该以被教练对象为中心，这样它才能跳出当前的觉察去审视自己。如下是几种常见的发问话术：

  1. 在这个关系问题中，你自己的角色是什么？
  2. 在这个新的角色里，激励你成功的主要因素是什么？
  3. 目前这个角色，你需要如何发展自己才能真正感到满意？
  4. 你对这个角色有哪些信念？
  5. 推动你走这么远的优势有哪些？
  6. 你希望如何评价自己？

发问的同时，也要帮助教练对象探索他们已经做过的事，这样能够帮助他们从一个新的角度去认识当前的处境，也能够帮助他们有意识的选择一种新的思考模式。这种思考模式能够使教练对象更广阔的思考目标成果，帮助他们把目标成果进一步明确的描述，甚至彻底改变目标成果的界定，这种思维方式更关注弄清前进的方向，而不是前进的方式。如下是教练发问的基本要求：

  • 发问清晰易懂。
  • 发问直奔主题。
  • 确保多数问题都是开放的。
  • 一次只提问一个问题。
  • 发问之后要给教练对象足够的时间思考和反思，然后再接着发问。

教练应该在具备高度的好奇心和耐心的空间里工作，最好的行动计划来自探讨，运用发问去探讨限制、恐惧以及优势，是为制定行动计划做出必要的准备。
