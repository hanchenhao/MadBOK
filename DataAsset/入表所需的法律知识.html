# 入表所需的法律知识

在数据驱动的现代社会中，数据不仅是企业运营和决策的关键因素，也是法律监督的焦点。数据资产入表作为数据处理的关键环节，其合规性和权益保护问题日益显著。数据合规不仅是企业遵循法律法规的基本要求，更是保护个人隐私、维护数据安全的重要保障。合规措施能够为企业筑起一道安全防线，确保数据不会泄露、误用或非法访问，从而有效避免经济损失和信誉损失。

从《民法典》《数据安全法》《个人信息保护法》等法律法规，到“数据十二条”以及相关的规范性文件和国家标准，均对数据合规使用提出了明确的要求。《信息技术服务数据资产管理要求》（GB/T40685-2021）第3.1条规定：“数据资产是合法拥有或控制的，能进行计量的，为组织带来经济和社会价值的数据资源”，所以“合法拥有或控制”是数据资源成为数据资产并且入表的必要条件。企业只有完成了数据合规，保证数据资产的合法性，才能启动资产入表的相关工作。

# 数据合规的相关法律体系

在我国互联网发展初期，缺乏专门的关于数据合规、数据保护的法律法规。即便涉及到数据保护，讨论也多聚焦于个人信息领域。这些关于个人信息保护的法律和法规，主要依靠并分布在通用法规中，随着个人信息泄露、网络攻击等问题日益显著，我国开始探索数据保护领域的立法工作，2015年7月1日《国家安全法》的实施，把数据安全提升到了国家安全的高度。然而在这一时期，我过关于数据合规的法规仍然具有分散性、概念性、内容较少、缺乏可参考性等特点。

2017年6月1日，《网络安全法》正式施行，2021年9月1日数据安全法正式施行，2021年11月1日《个人信息保护法》也正式施行。这标志着我过数据合规法律体系进入了一个飞速完善的阶段，这三部法规从不同的角度对数据合规进行了规范，共同涵盖了数据合规最基础的三大通用领域，被称为“三驾马车”。

《网络安全法》第一次从法律角度明确规定了个人信息保护问题，对网络运营者和服务提供者设定了安全保护义务，建立了关键信息基础设施的运行安全保护制度，提出了关键信息基础设施运营者个人信息和重要数据跨境传输规则，确定了个人信息保护规则。法律实施后监管机构采取了一系列强有力的行动，如工信部的APP整改行动、腾讯被广东网信办处罚，以及农行因数据和网络安全问题被银保监会处罚等。

《数据安全法》是我国首部专门针对数据领域的基础性法规。其旨在规范数据处理活动，保障数据的安全，同时促进数据的开发和利用。它也保护个人和组织的合法权益。并维护国家主权、安全和发展利益。该法律设计数据分类管理、数据安全保护、数据安全评估、数据处境、数据安全事件管理等方面，并对违法行为进行了明确的规定和要求。这部法规对于企业数据合规建设具有重要意义。

《个人信息保护法》是我国第一部专门针对个人信息保护领域的法规，其内容涵盖个人信息处理规则、个人信息处理者义务和个人信息跨境传输规则等多个方面，这部法律的颁布标志着我国网络安全及数据安全治理的整体法律框架初步形成。

以“三驾马车”为核心，《民法典》、《刑法》、《国家安全法》、《电子商务法》、《密码法》、《电子签名法》、《消费者权益保护法》、《测绘法》等法律法规在各个领域进一步完善了数据保护与合规监管的法律体系。国务院和各部位也陆续出台了有关网络电信安全、数据环境治理、数据分类分级、数据管理、数据交易、个人信息保护、数据出境等领域的行政法规。

除了从法律角度对数据合规法律体系进行总结归纳外，各细分场景下的数据合规法律法规、部门规章、规范性文件、标准等在2020年后如雨后春笋般不断出台，其中主要包含金融领域、出行领域、医疗健康领域、电信领域、邮政领域、工业领域等。

目前，我国在数据合规领域并没有统一的执法机构，而是由多个部门根据各自职能和法律法规的要求，分工协作进行监管和执法活动，目前参与监管活动的部门有网信办、工信部、公安部门、市场监督管理局和金融监管局等等。网信办的职责不仅限于监管和执法，还包括制度建设、标准制定、行业指导等多个层面，是数据治理的统筹管理部门。目前网信办主要整合和协调网络安全、网络数据安全和个人信息安全等工作，实施网络安全审查，组织执行数据跨境传输评估，规定个人信息保护的认定程序。该部门定期对全网常用软件和APP进行数据治理检测，清理并要求下架违法违规软件和APP。

工信部主要协调和保障国家信息安全，构建国家信息安全保障体系，指导和监督政府部门级关键行业的关键信息系统和基础信息网络的安全工作。协调处理网络与信息安全相关的重大事件。公安部门则是维护网络空间的安全和秩序，防止网络犯罪活动，保护公民个人信息和重要数据资产不收侵害，实施网络监控和调查，打击网络犯罪，监督网络运营商和服务提供商的数据处理活动。市场监管局主要集中在监督市场运行中的数据处理和利用活动，确保企业收集和使用个人信息时遵守法律法规，保护消费者合法权益，防止数据垄断和不正当竞争行为，确保市场公平和透明。

# 数据权益

数据权益的主体有两类。一类是数据来源者，一类是数据处理者。数据来源者者的权益主要由两部分构成。一部分是先在权利，它是指在数据相关权利形成之前，数据来源者对数据已经享有的权利，包括人格权、知识产权、、商业秘密权等。另一部分是有争议的财产权益，由于数据来源者众多且单个个体的数据价值稀薄，如果主张数据来源者占据财产权益可能会影响数据要素价值的实现，增加社会管理成本，目前比较折中的主张是：数据来源者只能享用自身产生数据财产权益。数据处理者对其处理的数据享有财产权，其主要包括数据资源占有权，数据财产使用权，数据财产处分权，数据隐私权等等。

根据《会计基本准则》对资产的定义，如果企业的数据资源能够被确认为资产，那么该数据资源首先要由企业拥有或控制，“拥有”是指企业享有某项资源的所有权，可以是企业生产经营活动中原始生产的经营数据、生产数据、业务数据或根据原始数据加工后衍生数据等第一方数据。“控制”是指企业虽然不享有某项资源的所有权，但该资源能被企业所控制。例如，对于企业通过外购等方式获取的数据资源，即使企业不拥有所有权，但是在遵守相关法律法规的前提下，依然可以享有数据的持有权、加工和使用权，在满足其他资产确认条件的前提下，该数据资产便可以按照会计处理规定“入表”。

# 入表探索

现阶段数据产权 登记相关的基础性制度、顶层设计尚在探索阶段。在实际操作中，各地知识产权局、数据局、财政局、司法厅、数据交易所都在积极探索数据登记的新形式。这些探索主要包括数据知识产权登记、数据资产登记、数据产品登记、数据要素登记及司法公正等多种方式。中共中央和国务院共同印发的《知识产权强国建设纲要（2021-2035）》以及国务院发布的《“十四五”国家知识产权保护和运用规划》，均对眼睛制定数据知识产权保护规则给予了高度重视。

2022年11月起，北京、上海、浙江、江苏、山东、附件、广东以及深圳等8个地方开展数据知识产权试点工作，各地陆续发表了相关工作方案或管理办法。具体实施详情如下图所示：

2022年8月广东省政府服务和数据管理局颁发全省首批公共数据资产登记证书，以促进公共数据资产入市流通，该凭证由省数据局监制，由数据供方凭借供需双方协议申领，数据主题授权需方使用其数据，需方申请数据资产凭证，并加盖电子签章。2023年8月21日，江西省数据资源登记平台正式上线，并完成全国首例全链路合规公证模式的书记资产入表，公证是一项国际通行的预防性法律制度，能够有效防范民商事纠纷，保障交易安全，是对司法公证数据确权的积极探索。
