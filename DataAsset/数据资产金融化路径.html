# 数据资产金融化路径

随着数字化浪潮的推进，数据资产可能会逐步成为企业价值的心增长点。他们不仅代表着企业在信息化时代的核心竞争力，更是驱动企业持续创新和发展的重要资源。其中数据资产金融化能够提升数据的价值和应用空间，可以在优化资产负债结构的同时，提高资金使用效率。本文将整理比较常见的三种数据资产金融化路径。

# 数据信贷

信贷包括存款、贷款、担保、承诺、赊欠等等，公司对于信贷的定义是以银行为提供主体，以法人和其他经济组织等非自然人为接受主体的资金借贷或信用支持活动，主要包括贷款、担保、承兑、信用证、信贷成年的等。在公司信贷中，银行作为主体，提供资金信贷或信用支持，连接资金的供应方（存款人）和需求方（借款人），资金供应方将其闲余资金存在银行，资金需求方找银行来满足借贷资金需求。银行在分析每一单业务时，必须要认真考虑成本与风险这两个关键因素，同时会采取一系列措施确保业务能够稳健运行。这些措施包括在贷款利率中加入风险溢价，也包括要求借款人提供价值担保（保证、抵押、质押、定金、留置）。

与技术、土地等生产要素成为知识产权、土地资产类似，数据也能拥有资产属性，也可以用于融资和资金运作。数据信贷这种新兴的融资模式正应运而生。数据信贷是指企业用其合法拥有或控制的、产权归属明晰的、依法可转让的数据资产作为担保，按照国家法律法规和其他相关信贷政策，从商业银行等金融机构获得资金，并按期偿还本息的一种融资方式。

目前在数据信贷的探索中，最常见的担保方式是质押，即企业将满足条件的数据资产作为质押物移交给商业银行等机构，作为对银行债权的担保。如果贷款违约，银行有权变卖质押的数据资产弥补损失。因为我国数据资产处于“散点式”发展态势，各地方知识产权局、数据局、财政局、司法厅、数据交易所有的将数据资产按照知识产权的路径进行探索，有的则把数据资产当成一种新型财权来进行研究。数据质押贷款流程如下图所示：

数据资产作为质押物首先应进行登记，公示质押贷款申请人对数据具有合法的持有权、加工使用权和经营权，避免数据资产被非法占用或侵犯。经过权属确认的数据资产将成为数据资产质押贷款中是质押物。我国数据资产具体探索处于“散点式”发展状态，目前数据资产登记大体可分为数据知识产权登记和新型数据财产权登记。

按照各地出台的数据知识产权管理办法，具体承办数据知识产权登记工作的机构往往是各地区的知识产权中心、标准技术研究院等机构。依照各地的《知识产权登记管理办法》，数据产权登记具体有如下6个步骤，登记成功后便会发放数据知识产权登记证书，有效期通常为2~5年：

  1. 数据存证或者公证：在符合法律法规及相关规定的机构利用可信技术进行电子数据存证或证据保全公证。
  2. 申请登记：自行申请/委托代理机构办理网上数据知识产权登记。
  3. 形式审核与审查补正：登记机构收到申请后，对登记申请书和必要材料进行形式审核。经形式审核不符合登记申请书、必要材料要求的，登记机构一次性告知申请人需要补正的全部信息，申请人应补正，未补正的视为撤回申请。
  4. 登记公示：公示内容包括申请人、数据知识产权名称、应用场景、数据来源、算法规则简要说明等信息。
  5. 异议处理：对于处于公示期的数据知识产权，可以就公示内容向登记机构提出异议，并提交异议申请书和证明材料。
  6. 发证及公告：登记机构核准登记，发放数据知识产权登记证书，并予以公告。

因为数据登记形式非常多样，包括数据资产登记、数据产品登记、数据资源公证等多种形式，但形式上比较清晰，以上海数据交易所的登记流程为例，整个过程大致分为4步：

  1. 数据产品的权利者向专门的数据权属登记机构提交登记申请。
  2. 登记机构对申请内容进行初步审查。
  3. 组织安排律师事务所开展合规审查，组织安排质检所开展质量检测，组织安排资产评估事务所开展资产评估。
  4. 如果上述环节通过审核，数据权属登记机构向申请者发放数据登记凭证，如未通过则驳回并说明理由。

银行在评估数据资产质押项目时，通常主要关心三个核心点，即数据资产的合法性、价值评估的可靠性和数据资产价值的稳定性。现代数据产权制度并不成熟，因此银行会关注企业是否具备合法持有或经营数据的权利。关于数据资产的价值评估，银行需要基于充分的背景调查结果进行审核，这个过程中可能会重新评估数据资产的价值，以确保评估结果的可靠性。在数据资产价值评估难以定量的情况下，银行会转向评估数据资产的历史订单合同以及企业发展潜力，更侧重于数据资产的市场价值，类似于应收账款融资。

中共中央、国务院印发的《数字中国整体布局规划》中明确要求：释放商业数据价值潜能、加快建立数据产权制度、开展数据资产计价研究、建立数据要素按价值共享参与分配机制。全国各地都纷纷开展可数据信贷方面的探索，例如北京某A股科创板上市公司，是集物联网、数据采集、数据融合、数据分析为一体的大数据服务企业，该公司现有原始数据万亿条，经过清洗加工后形成数据产品的数据有200亿条，经过中国电子技术标准化研究院、北京市大数据中心、北京国际大数据交易有限公司、国信优易数据股份有限公司与中联资产评估集团共同组成的工作组评估后，此公司的两个项目的数据资产估值达到了6000万元。2022年10月12日，北京银行城市副中心分行成功落地收笔1000万数据资产质押融资贷款。

# 数据资产出资入股

《中华人民共和国公司法》第四十八条规定：“股东可以用货币出资、也可以用实物、知识产权、土地使用权、股权、债权等可以用货币估价并可以依法转让的非货币财产进行出资。”总的来说，出资入股的方式可以分为货币性资产和非货币性资产，非货币性资产包含实物资产（机器设备、原料、零部件、货物、建筑物、厂房）、知识产权（专利、发明、实用新型、软件著作权、专有技术等）、土地使用权及股权债权等其他形式资产。非货币性资产出资入股是指用这些非货币性质资产设立新的企业，或者参与企业的增资扩股、定向增发股票、重组改制等投资行为。

站在现代企业制度的角度来看，承认数据作为一种生产要素参与分配的价值，其核心是要将企业采集、持有、控制、处理、加工数据的权益转化成股权。用数据资产出资入股，可以让投资人将其合法拥有的、产权归属明晰的、依法可以转让的数据资产转化为企业的股权，成为企业的股东，并按照股权平等原则和贡献度参与分配。数据资产出资入股流程如下：

2023年8月30日，在“2023智能要素流通论坛暨第三节DataX大会”上，青岛某科技研究院有限公司与另外两家公司进行全国首例数据资产作价入股签约仪式，该数据资产作价入股落地分为如下4个环节：

  1. 数据资产登记。2023你年4月15日，青岛公共数据运营平台对该公司数据资产进行合规审查；2023年4月20日审查通过，并为其颁发《数据资产登记证书》。
  2. 数据资产评价。2023年8月23日，青岛大数据发展促进会依据《数据资产价值与收益分配评价模型》团体标准，对该数据资产进行评价，最终出具《数据资产评价报告》。
  3. 数据资产评估。2023年8月28日，第三方专业评估机构对该公司的相关数据产品出具了资产评估报告。
  4. 数据资产入股。2023年8月30日，该公司把基于医疗数据开发的数据保险箱产品，以作价为100万元入股的方式，与另外两家公司签订组建成新公司。

# 数据资产证券化

资产证券化是指将缺乏流动性，但能够产生可预见稳定现金流的资产，通过一定的结构安排，对资产中的风险与收益要素进行分离和重组，进而转化为在金融市场上可以出售、可以流通的证券的过程。简单来说就是将能够产生稳定现金流的资产出售给一个专门从事资产证券化业务的SPV（special purpose vehicle）发行证券，并用发行证券所募集的资金支付购买资产的费用。

如果我们把企业对数据的行为抽象地分为投入和产出，那前期规划、数据采集、数据清洗、数据分析、数据应用、数据运维等步骤都意味着巨额成本投入，对企业来说，数据资产证券化是一个重要的“变现”方式。当数据资产纳入企业资产负债表并成为一种资产类型（无形资产或存货）后，选取其中质量较好、公信力强、预期明确的成熟资产，以期未来收益现金作为偿付基准发行证券产品。这种将数据资产未来收益即期变现的过程，可以参考知识产权等无形资产证券化。

目前可行性较高的数据资产证券化的路径是：DAITs（Data Asset Investment Trusts，数据资产投资信托基金）模式。通过对数据资产的投资信托，由专业运营团队管理，以获取稳定的数据资产营收，形成基础底层资产，接着将具备稳定收益但流动性较低的底层资产及金融资产转化为可上市发行的证券。

在“新基建”的大环境下，这种投资信托模式很适合发挥基础数据资产的社会价值，能够利用社会资金来充分利用底层的基础性存量资产，让公众也能在数据资产发展中受益。数据资产通过参考知识产权来确定和保护权属，通过信托方式重新设置权益结构，不仅能充分发挥资产的正外部性，而且产生的收益也更适合证券化。这种基金架构也有助于解决一般证券化产品在二级市场交易流动性不足的问题，可以通过采用投资者适当性管理、产品分级管理等方式，让投资者承担与他们匹配的风险。

商务部在《全面深化服务贸易创新发展试点总体方案》中明确提出要“推动数据资产的商品化、证券化”，进一步强调了数据资产证券化的重要性。地方层面，各省市区也积极响应，2023年7月5日，在浙江自贸试验区杭州片区，某公司23年度第一期杭州高新区数据知识产权定向资产支持票据在中国银行间市场交易商协会成功簿记，发行金额1.02亿元，票面利率2.80%，发行期限358天，是全国首单包含数据知识产权证券化的产品。本项目由杭州高新区市场监管局（知识产权局）等单位牵头，以区内12家企业的145件知识产权（包含部分数据知识产权）作为抵押物，帮助企业获得证券化融资，这从实操层面形成了数据要素产权化的有效创新路径，打破传统融资方式，实现“知产”到“资产”的转换。
